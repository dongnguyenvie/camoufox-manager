# Organization and sheets

## Tags and groups

- **Tags** label profiles (many per profile). Filter the table by tag.
- **Groups** put each profile in one group.
- **Saved views** store a combination of filters, sorting and visible columns.

## Bulk actions

Select several profiles in the table (click, drag or Shift to extend) and apply an action to all of them:
start, stop, tag, group, assign a proxy, and so on. The result of each profile is listed. Bulk actions are
limited to a fixed number of profiles per request.

## Spreadsheet view

The profile table works like a sheet: click a cell to select, drag or Shift-click to extend, and copy the
selection with Cmd+C as TSV to paste into Excel or Google Sheets.

## Sheets import and export

Export the table as xlsx or csv, or import profiles from an xlsx or csv file.
